# ISSUE-E15-03 — Integrate Coltrane Bridge Suggestions into the Bridge UI and Preview Flow

## Objective

Make Coltrane changes available through the existing bridge suggestion and preview workflow in a way that is easy to audition and apply.

## Background

The app already has progression sidebar interaction patterns for previewing and applying bridges. This new bridge type should fit into that system rather than invent a parallel workflow.

## Scope

1. Surface Coltrane changes as a selectable or discoverable bridge type.
2. Integrate it into preview and insertion flows.
3. Keep the feature clearly labeled as an advanced harmonic option.
4. Ensure the experience remains approachable for non-expert users.

## Requirements

### UX

- The bridge should be previewable before insertion.
- The UI should clearly communicate that the suggestion is an advanced reharmonization.
- The workflow should remain consistent with other bridge suggestions.

### Accessibility

- The feature must be keyboard operable.
- Preview and apply controls must expose clear semantics.
- Dynamic bridge-preview changes should be perceivable without relying only on sound.

## Acceptance Criteria

- [ ] Users can discover Coltrane bridge suggestions through the existing UI.
- [ ] Users can preview the bridge before inserting it.
- [ ] Users can apply the bridge to the progression without confusion.
- [ ] The interaction remains consistent with the rest of the bridge system.
